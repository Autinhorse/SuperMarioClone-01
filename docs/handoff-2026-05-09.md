## What's done (committed and on origin/main)

### Game (`games/ricochet/`)

- **`delay` parameter** on Cannon, Spike, SpikeBlock, Turret, LaserCannon.
  Lets the level author stagger periodic hazards. Editor stepper UI on each
  element. 0.5 s steps, default 0. See `feel.ts`, `Player.ts`, `PlayScene.ts`,
  `editor/paramsHtml.ts`.
- **Editor auto-select after placement.** Click Cannon → click cell → the
  newly placed cannon is already selected and its full params panel is
  showing (so the user doesn't have to click it again to tweak Period /
  Delay). `applyTool` returns `boolean`; `AUTO_SELECT_TOOLS` whitelist
  excludes wall/coin/spawn/exit/portal/eraser. `EditScene.ts`.
- **Camera shake on wall hit.** Distance- and axis-aware. Threshold 10
  cells, +10 % per cell above (so 10→100 %, 15→150 %, 30→300 %). Base
  intensity halved to 0.0025 after first iteration. Vector2 shake locks
  one axis. Player emits `wall-hit` with `{axis, surface, cells}`.
  `feel.ts:SHAKE_*`, `Player.ts`, `PlayScene.shakeOnWallHit`.
- **Coin counter top-left, debug text top-right.** Swapped the two HUD
  positions — the player-facing counter sits where the user expects it.
- **Sounds wired (13 files).** `sounds.ts` central loader. Map:
  - Death / Jump / Fly — `Player.ts`
  - HitWall / LandGround — branched on `wall-hit.surface`
  - GetCoin / GetKey / HitGlass / Teleport / LevelCompleted — `PlayScene.ts`
  - Portal — `Portal.handlePlayerOverlap`
  - UI_Button — Menu + Edit palette nav buttons + back / dialog buttons
  - BGM (loop) — added/get on `PlayScene.create`, persists across
    `scene.restart` (cross-page teleport, death respawn). Stopped in
    Menu/Edit `create()`. Volume 0.2; SFX 0.7.
- **Portal cooldown extended to handle nearby-wall rebounds.** Source
  portal `PORTAL_COOLDOWN_SEC = 0.3`; destination portal
  `PORTAL_DESTINATION_COOLDOWN_SEC = 0.5`. Pure timer, no event-based
  release (we tried distance + key/wall release; reverted to pure timer
  for simplicity).
- **Campaign 12 → 10.** `feel.ts:CAMPAIGN_LEVEL_COUNT = 10`. MenuScene
  grid + PlayScene last-level dialog use it. Last-level copy:
  "Congratulations! You cleared all 10 levels." No "Next Level" button.
  Files `level-11.json` and `level-12.json` deleted.
- **Menu scene background image.** `.menu-overlay` CSS uses
  `/sprites/background.png` cover.
- **No-floor spawn now accepts input on frame 1.** When `idle()` detects
  no floor, it transitions to `FALLING_INPUT` and immediately runs
  `fallingInput(dt)` on the same frame so the user's first arrow-key
  press isn't swallowed by the early-return. `Player.ts:idle`.
- **Web embed: editor Done button + back-to-edit during test-play.**
  - EditScene's "Menu" button is no longer hidden in embed mode; renders
    as "Done" instead of "Menu". Click → unsaved-changes confirm if
    dirty → `postToParent('exit-edit', { levelId })`.
  - PlayScene's back button is now built in embed mode when
    `launchedFromEditor=true`, so a test-play from the editor has its
    own ◀ Edit button inside the iframe.
  - `EditFrame.tsx` handles `exit-edit` → `router.push('/ricochet/play/{id}')`.
